# Devin Guide — rules from the user (Kitesso / Bosonaa) for the Afaan Oromo learning app

These are the user's own rules, recorded verbatim. They are binding for repo `Bosonaa/learn-afaan-oromo`.
Read them before any work in that repo, follow them, and append any new rules the user gives — never edit
or reinterpret the user's wording, and never add rules of my own to this list.

## Devin Guide

1. Design application that will be used on kids/students devices to learn languages.
2. We will start with Afaan Oromo lesson
3. Most of the current designs are OK. It should follow Duolingo like design and flow.
4. Initial lesson will use the English-oromo.pdf I provided, and ask in English and users will respond by choosing from one of the choice list.
5. Currently there is no audio choice. Meaning do not attempt to provide an audio question or answer. It can be used in the future. So, preserve what already created and isolate from the app.
6. There should be no free form answer. It will only be English to Afaan Oromo choice and vice versa.
7. Next phase after dictionary like lesson/lessons, it will be to create a phrase in English and users chose from possible afaan oromo phrases.
8. Continue to track users progress on a device.
9. If you need clarification or additional materials, ask, do not assume.
10. If you find better resources to use to create this lesson, let me know. It must have adequate words. It can’t be a sample.
11. There will be a dictionary feature in the future, but that will leverage existing materials. Currently it should be considered future phase.
12. PR should always be against develop branch. not main.
